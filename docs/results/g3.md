# Gate G3 — the live demo: PASS

Checklist, each item exercised against the real running system (server on 7311 with `l1-diffusion-mix`, Vite on 5173, this machine):

- **Server starts clean with a real checkpoint** — yes; also falls back to the stub with a loud banner when no checkpoint exists.
- **UI connects and reports the model** — rail shows `l1-diffusion-mix · 9.9m params · cuda`, levels populated from `/api/levels`.
- **L1 solve animates and grades** — `47+3=50`, confidence-colored commits, CORRECT badge (screenshot: `real-run-correct.png`). One server bug found and fixed on the way: it graded the whole canvas instead of the generated region.
- **Infill fills a hole from both sides** — `18+__=45 → 27` live (screenshot: `infill-live.png`), after the mix-objective retrain documented in the journal. Systematic check: 200/200 equation-valid.
- **Verdict badge matches the external checker** — correct/wrong/n-a all observed.
- **Ordering switch changes commit order** — enforced by test (`test_orderings_change_commit_order`) and visible in the ablation grid; the live UI exposes the same flag.
- **Scrub/replay works** — frames replay backward and forward; committed cells never change within a replay (the honesty invariant, also test-enforced).
- **Starfield, parallax, glare** — square stars drifting with pointer parallax at z −1, 220px sage glare on panels, verified in screenshots.
- **Reduced motion** — three code layers (global CSS kill, `prefersReducedMotion()` gate in starfield/glare, transition tokens). Verified by code review and the CSS media block; not exercised via a live OS toggle in this pass — noted as the one soft check.
- **Cold launcher** — `scripts\run.ps1` starts server + UI from a cold shell; checkpoint auto-discovery picks the newest diffusion run.
- **Latency budget** — 5.3ms/step CUDA, 6.8ms/step CPU (30-run average, capture on). The 120ms default playback throttle, not the model, sets the pace — by design, so you can watch.

Verdict: the loop the project promised — train here, run here, watch it think here — exists and works.
