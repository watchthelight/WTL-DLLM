# Gate G1 — coherence: PASS

The gibberish risk didn't materialize. Both documented prior laptop attempts at from-scratch text diffusion produced nonsense; this one didn't, and it declared itself early — by step 4,000 the training previews were already emitting correct, properly-terminated answers (`82-12=70`, `52+63=115`, `26-26=0`).

## The numbers

200 held-out L1 prompts, answer region fully masked, steps = masked count, ordering = confidence, temperature 0, seed 0. Eval config on every row per the ledger.

| model | weights | well-formed | accuracy |
|---|---|---|---|
| g1-diffusion (10M, 20k steps) | raw | 1.000 | 1.000 |
| g1-diffusion | ema 0.995 | 1.000 | 1.000 |
| g1-ar twin (same trunk, causal) | raw | 1.000 | 1.000 |

Gate threshold was ≥0.95 well-formed. Both models cleared it at 1.000 — no pivot needed, the encoder-fallback path stays unused.

## Context that keeps these numbers honest

- The `eval` split draws the training distribution and can overlap train strings — L1's discrete space (~9.6k unique strings under the operand bands) is nearly exhausted by a 200k-row corpus, so this split measures memorization + format learning, exactly as `docs/architecture.md` says it does. It is the right split for a *coherence* gate and the wrong split for a capability claim.
- The capability question — does anything generalize? — belongs to the perturbed split (operands from digit bands the model has never seen, every addition carrying). That's Gate G2, next.
- Training: RTX 5070 Laptop, ~13 minutes per model, ~89k tok/s sustained, 0.56GB VRAM, train loss effectively 0.0 by step 18k. The EMA-vs-raw comparison showed no difference at this run length, as expected with decay 0.995 over 20k steps.

## Verdict

G1 passes for both architectures. The interesting comparison starts at G2.
