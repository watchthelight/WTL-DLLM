# 2026-07-25 — setup

Repo born. Identity, conventions, scaffold, scripts, all in before lunch.

Hardware turned out nicer than planned for: RTX 5070 Laptop (8GB, Blackwell, bf16 fine), 24 threads, 31GB RAM. The probe recommends the gpu-10m preset. System python already had torch 2.11.0+cu128 working against the card, so instead of pulling 3GB into a fresh venv I did `uv venv .venv --system-site-packages --python 3.11` and layered just pytest + numpy on top with `uv pip install pytest numpy`. Torch imports, cuda says yes, moving on.

One early lint catch: the two research docs were missing frontmatter. Fixed, `lint_headers.py` runs clean. Also scrubbed absolute local paths out of the committable docs — sibling-relative references only.
