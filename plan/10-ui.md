# Phase 10 — UI

`ui/`. Svelte 5 + Vite + TypeScript SPA. The methodology is ported from `research/pawtropolis-ui-recon.md` (sections B, D, H — open it and keep it open); every constant below comes from there. Theme: dark alpine/sage on OLED true black. Identity: square everything. **Naming law: zero paw-anything — keys/events/classes are `wtl-*`.**

Anti-AI-pattern checklist (recheck before phase close): no purple/indigo gradients, no glassmorphism cards, no emoji in headings, no "AI-powered ✨", no rounded-blob hero, no perfectly symmetric three-feature grid, no Inter-for-everything. Copy sounds like a person (humanize rules).

## Story 1 — scaffold + tokens

- `npm create vite@latest ui -- --template svelte-ts`; deps: `@fontsource-variable/figtree`, `@fontsource/space-mono`. No Tailwind, no UI kit — hand-rolled CSS custom properties (the methodology).
- `ui/src/styles/tokens.css` — OKLCH, single seed `--accent-h: 152; --accent-c: 0.075`:
  ```css
  --void: oklch(0% 0 0);                      /* OLED true black — the one deliberate departure from source (was 15.5%) */
  --surface:   oklch(18% 0.013 var(--accent-h));
  --surface-2: oklch(22% 0.015 var(--accent-h));
  --surface-3: oklch(26% 0.016 var(--accent-h));
  --ink:   oklch(93% 0.014 110);  --ink-2: oklch(75% 0.016 140);
  --ink-3: oklch(60% 0.014 150);  --ink-faint: oklch(48% 0.012 150);
  --line: oklch(33% 0.014 var(--accent-h)); --line-soft: oklch(27% 0.012 var(--accent-h)); --line-strong: oklch(46% 0.02 var(--accent-h));
  --sage: oklch(78% var(--accent-c) var(--accent-h)); --sage-bright: oklch(85% 0.095 var(--accent-h));
  --sage-deep: oklch(58% 0.085 var(--accent-h)); --sage-soft: oklch(30% 0.041 var(--accent-h)); --sage-fill: oklch(24% 0.03 var(--accent-h));
  --good: oklch(74% 0.09 150); --warn: oklch(78% 0.1 78); --danger: oklch(70% 0.11 32); --info: oklch(74% 0.07 220);
  --radius: 2px;                              /* every radius token is 2px — square is the signature */
  --shadow: 0 1px 0 oklch(100% 0 0 / 0.03);   /* hairline highlight; depth comes from borders + surface steps, never blur */
  --font-body: "Figtree Variable", system-ui, sans-serif; --font-mono: "Space Mono", monospace;
  --ease-spring: cubic-bezier(0.34,1.56,0.64,1); --ease-smooth: cubic-bezier(0.4,0,0.2,1); --ease-out: cubic-bezier(0.22,0.61,0.36,1);
  --dur-fast: 150ms; --dur-med: 250ms; --dur-slow: 400ms;
  ```
- Global rules: animate ONLY transform/opacity/border-color; body bg `var(--void)`; `:focus-visible { outline: 2px solid var(--sage); outline-offset: 2px }`; `font-variant-numeric: tabular-nums` on all numeric readouts; reduced-motion global kill (`* { transition-duration: 0s !important; animation-duration: 0s !important }` inside the media query) plus a `prefersReducedMotion()` TS helper every animated component checks.

## Story 2 — `Starfield.svelte` (square stars)

Port the recon constants exactly; one fixed canvas, `inset:0; z-index:-1; pointer-events:none`, `aria-hidden`:
- Palette: star `[232,240,230]`, accent `[150,200,165]`, count 120, 14% accent-tinted.
- 3 layers round-robin: `{parallax:.25, speed:.12, size:.7} {.5,.22,1.0} {1.0,.36,1.4}`.
- Star: radius `size*(0.6+rnd*0.8)`, baseAlpha `0.25+rnd*0.55`, twinkle freq `0.4+rnd*1.1` rad/s, random phase.
- Loop: `curX += (pointerX-curX)*0.04`; alpha `base + sin(t*tw+phase)*0.18`; x-shift `curX*layer.parallax*26`; drift per frame `x -= speed*mult*0.6; y += speed*mult*0.5`, toroidal wrap.
- **Draw `fillRect(px-r, py-r, r*2, r*2)` — square stars.** (The one aesthetic departure from source, on brand.)
- Pointer: normalized −1..1 from viewport center, `{passive:true}`. DPR capped at 2. Resize rebuilds. Reduced motion → single static frame, no listeners.
- Tuning: `localStorage['wtl-star-density']` (0.4–1.6) and `['wtl-star-speed']` (0.4–1.8), re-read on window event `wtl:starfield`.

## Story 3 — layout + chrome

- Shell: slim left rail (fixed, `--surface`, 1px right hairline) with mono uppercase eyebrow nav (0.6rem, tracking 0.14em, `--ink-3`, active `--sage` + `inset 2px 0 0 var(--sage)`); main content transparent over the starfield.
- Section dividers: the **tick-rule** — 6px square rotated 45° in `--sage-deep` + mono uppercase label + 1px dashed hairline to the right.
- Panels: `--surface` + 1px `--line-soft`, radius 2px, padding `clamp(14px, 2.5vw, 24px)`, hairline shadow.
- Card glare (pointer occlusion): pointermove sets `--mx/--my/--glare`; overlay span paints `radial-gradient(220px at var(--mx) var(--my), oklch(78% var(--accent-c) var(--accent-h) / 0.14), transparent 60%)`, opacity transitions `--dur-fast`. Optional tilt: `perspective(700px)` rotateX/Y max 5°. Both gated on `(hover:hover)` and reduced-motion.
- Grain (subtle, panels only): 180px feTurbulence SVG tile (`baseFrequency 0.85, numOctaves 2`), opacity 0.6, `mix-blend-mode: overlay`.

## Story 4 — the denoise board (centerpiece)

- `DenoiseBoard.svelte`: a row-wrapped grid of fixed-size square token cells (mono font). Cell states:
  - **masked**: `--surface-2` block, faint `·` glyph in `--ink-faint`
  - **prompt**: `--ink`, `--surface` bg (committed from frame 0)
  - **just committed** (this frame): 250ms flash — scale 1.06→1 (`--ease-spring`) + color by confidence bin: <0.3 `--warn` · 0.3–0.7 `--sage-deep` · >0.7 `--sage-bright`
  - **committed** (settled): fades to `--ink` over ~1s. Frozen means frozen — no cell ever changes after commit (mirror of the sampler's honesty invariant).
- Playback: frames arrive from the WS store; a playback clock (user speed slider, 0–500ms/frame) replays them; scrub bar to step back through history (re-render past frames — pure data, no re-inference).
- Readouts right of the board: step counter as a slot-reel (translateY digit strip, `will-change: transform`, mask-image edge fade), masked-remaining count, per-step mean confidence sparkline (tiny inline SVG), final verdict badge (`--good`/`--danger`/`--ink-3` for correct/wrong/n-a).

## Story 5 — controls + client

- `Controls.svelte`: task preset select (L1–L5 from `/api/levels` + custom prompt + **infill** toggle with prefix/suffix/hole inputs), canvas length, steps, ordering select (random/confidence/margin/entropy), temperature (0 default), playback speed, seed field, run button (Ctrl+Enter). Small print under advanced controls, honest microcopy — e.g. ordering: "which masked spot gets filled next"; temperature: "0 = deterministic; this model does math, keep it 0".
- `ws.ts` store: connect `ws://localhost:7311/ws/generate`, send request, accumulate frames, expose status (idle/streaming/done/error), reconnect-with-backoff, `VITE_WS_URL` override.
- `theme.ts`: `data-theme` on `<html>`, `wtl-theme` in localStorage, pre-hydration inline script in `index.html` (no first-paint flash). One theme ships (dark); the token system makes light trivial later.
- Settings drawer: star density/drift sliders (writes the `wtl-*` keys, fires `wtl:starfield`), reduced-motion note.
