# wtl-dllm

A tiny diffusion language model you can watch think — trained from scratch on a laptop, aimed at arithmetic, rendered as live token denoising in the browser.

Status: building. The plan is public in `plan/`, the research that shaped it is in `research/`, and the honest results (good or bad) will land in `docs/results/` as they happen.
